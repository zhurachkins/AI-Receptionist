# Knowledge Sources

Use these sources in order.

## Priority

1. Current project files and `Salon AI MVP v26.json`.
2. Official n8n documentation: https://docs.n8n.io/
3. Official n8n workflow templates: https://n8n.io/workflows/
4. Verified external template repositories:
   - https://github.com/enescingoz/awesome-n8n-templates
   - https://github.com/restyler/awesome-n8n
   - https://github.com/wassupjay/n8n-free-templates
   - https://github.com/zie619/n8n-workflows

## Rules

- Use official n8n documentation first when node behavior or parameters are uncertain.
- Use official workflow templates before inventing logic.
- Use external repositories only as reference material.
- Never copy a full external workflow into this project.
- Search Telegram workflow examples first when changing Telegram logic.
- Search Google Calendar workflow examples second when changing calendar logic.
- Search AI Agent and Memory examples when changing conversation logic.
- Reuse proven patterns only when compatible with the current workflow and n8n Cloud.
- Analyze the entire workflow before edits.
- Preserve existing node names and connections.
- Explain workflow impact before changes.
